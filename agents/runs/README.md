# Evidencia de ejecuciones

No existen ejecuciones todavia. Los artefactos futuros de cada run se guardaran
localmente en una subcarpeta por run_id; estan ignorados por Git por defecto.
Solo evidencia sanitizada y revisada se incorpora al cambio OpenSpec.

Registro minimo: change_id, revision aprobada, aprobador/fecha verificables,
tareas autorizadas, modelo/version, coste/tokens, herramientas usadas, diff,
comandos y exit codes reales, escenarios, bloqueos y decision humana final.

No guardar secretos, prompts con datos reales ni tokens de sesion. No confundir
un resumen LLM con stdout, prueba ejecutada o aprobacion autenticada.
